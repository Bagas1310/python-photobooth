# 📸 Python Photobooth

Aplikasi photobooth interaktif berbasis Python yang dilengkapi dengan fitur pengambilan foto otomatis, efek suara menggunakan `pygame`, dan pemrosesan gambar menggunakan `OpenCV`.

---

## 🚀 Fitur Utama

* **Live Camera Preview:** Pratinjau kamera secara *real-time*.
* **Audio Feedback:** Memutar efek suara (seperti *shutter* kamera) menggunakan `pygame`.
* **Auto Save:** Menyimpan hasil jepretan secara otomatis ke dalam folder penyimpanan.

---

## 🛠️ Teknologi yang Digunakan

* **Language:** [Python 3.x](https://www.python.org/)
* **Library:** 
  * [OpenCV (`opencv-python`)](https://opencv.org/) - Pengolahan kamera & gambar
  * [NumPy](https://numpy.org/) - Komputasi numerik / array
  * [Pygame](https://www.pygame.org/) - Manajemen efek suara

---

## 💻 Cara Menjalankan Project

Jalankan perintah berikut di terminal:

```bash
# 1. Clone repository ini
git clone [https://github.com/Bagas1310/python-photobooth.git](https://github.com/Bagas1310/python-photobooth.git)

# 2. Masuk ke folder project
cd python-photobooth

# 3. Install seluruh dependencies dari requirements.txt
pip install -r requirements.txt

# 4. Jalankan aplikasi
python photobooth.py
